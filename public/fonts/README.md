# Fonts

`JetBrainsMonoNerdFont-*.woff2` are JetBrains Mono, patched with icon glyphs by the
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) project (v3.3.0), converted to WOFF2.

- JetBrains Mono: Copyright 2020 The JetBrains Mono Project Authors, SIL Open Font License 1.1.
- Nerd Fonts patcher and glyph sets: MIT License, Copyright (c) 2014 Ryan L McIntyre.
  Bundled glyph sets carry their own licences (Font Awesome: SIL OFL 1.1; Devicons: MIT;
  Material Design Icons: Apache 2.0; and others listed in the Nerd Fonts repository).

The UI text face, Inter, is loaded from Google Fonts (SIL Open Font License 1.1).
